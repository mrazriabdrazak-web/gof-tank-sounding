GOF Fleet Tank Sounding Calculator v8.4.0

Single offline calculator for the six GOF fleet vessels. Vessel-specific calibration data are embedded in this file. Source SG is shown for reference. Fuel-oil tonnes can optionally use the current BDN density at 15°C.
BDN density is the density at 15°C stated on the Bunker Delivery Note. When enabled, fuel-oil tonnes are calculated from the approved calibrated volume × BDN density. Source calibration volume is unchanged.
Dolphin Satu: this source contains tank-specific trim correction tables. Enter the observed vessel trim. Negative = trim by forward; positive = trim by stern. The calculator applies the supplied correction table before using the no-trim/no-heel sounding table. Other vessels use their source conditions without an invented trim correction.
Fuel density rule: Source SG comes from the approved tank calibration document. BDN density @15°C is entered from the current bunker delivery note. It affects only Fuel Oil ROB tonnes when the BDN option is enabled; it does not change calibrated volume.
BDN calculation: BDN mode OFF — source calibration tonnes used.

Data integrity: This program uses the vessel-specific sounding/calibration datasets prepared from the supplied vessel source documents. It does not substitute a common calibration table between vessels. Linear interpolation is used between adjacent source soundings; extrapolation is not permitted. For Dolphin Satu, the supplied tank-specific trim correction tables are used. For the other vessels, no trim/heel correction is invented where the source calculator is based on its stated calibration condition.
